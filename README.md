Hello! My program is supposed to simulate a group of heroes entering a dungeon. 
Before you press the start button, you must first add the player to the game
by going to the Game section in the menu bar and clicking Add Player. You must at
least enter the player's first name to start the game. Once you start the
game, the Confirm and Get Data button will be available to click. The Get Data button 
gets the player's information, such as their name, amount of coins, and rewards,
and writes it into a file. The text area will describe the scenario and will 
instruct you on which skills to use and on whom to use them. After you have either
lost or won, the Next Dungeon button will become available, and you will be able to 
continue to earn more coins or items.
